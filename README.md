# YUME

Веб-каталог аниме с поиском, фильтрами и карточками тайтлов. Проект находится в разработке; доступность функций зависит от текущей конфигурации и проверок окружения.

**Staging:** https://yume-staging.makellodima5.workers.dev/

Этот репозиторий предназначен только для staging-среды YUME. Production-ресурсы и production-деплой не входят в область этого репозитория.

## Возможности

- Каталог метаданных аниме на основе Shikimori с хранением в Cloudflare D1.
- Главная страница и подборки: популярное, новинки, анонсы и выходящие сейчас тайтлы.
- Страницы тайтлов с описаниями, рейтингами, похожими тайтлами и доступными YouTube-трейлерами.
- Поиск, фильтры, сортировка и постраничная навигация с состоянием в URL.
- Русский и английский интерфейсы.
- «Избранное» и «Мой список» с хранением в браузере; для авторизованных пользователей предусмотрена синхронизация через Telegram.

Каталог хранится в staging Cloudflare D1 и может расширяться через административные инструменты. Общий объём ограничен реальными квотами и ёмкостью Cloudflare, но код приложения не должен вводить искусственный общий лимит на число записей. Это каталог метаданных, а не исчерпывающая база всех аниме.

## Ограничения текущей версии

- **Просмотр серий:** полноценный плеер серий в текущей версии не реализован. На страницах могут быть доступны YouTube-трейлеры.
- **История просмотра:** полноценный серверный прогресс просмотра и продолжение с сохранённой позиции не реализованы.
- **Аккаунты и синхронизация:** предусмотрены Telegram-связанные сценарии; их работа зависит от настройки Telegram credentials и секретов именно в staging.
- **Telegram Mini App:** перед публичным запуском нужна отдельная проверка сценариев и настройки окружения.
- **Реклама:** рекламные места удалены из пользовательского интерфейса. Рекламные кампании не включены.
- **Правовые документы:** проекты документов требуют заполнения и проверки перед публикацией.
- **Домен:** постоянный собственный домен ещё не указан.

## Технологии

- React, TypeScript
- TanStack Start и TanStack Router
- Vite и Tailwind CSS
- Bun
- Cloudflare Workers и Nitro
- Cloudflare D1, binding базы данных: `YUME_DB`
- Cloudflare KV и Queues для staging-кэша и фоновых задач
- Shikimori API как источник метаданных

## Локальная разработка

### Требования

Установите Bun и совместимую с зависимостями версию Node.js.

### Установка

```bash
bun install --frozen-lockfile
```

### Запуск dev-сервера

```bash
bun run dev
```

## Проверки

Перед отправкой изменений запустите:

```bash
bun run lint
bun run test
bun run typecheck
bun run build
```

Доступны также `bun run test:watch` для запуска тестов в режиме наблюдения и `bun run preview` для локального просмотра сборки.

## Публикация staging

Для staging используется только `wrangler.staging.jsonc`. Команда публикации:

```bash
bun run deploy:staging
```

Команда выполняет сборку и затем staging deploy. Не запускайте её одновременно с отдельной автоматической сборкой в CI, если это приведёт к дублированию build.

Не используйте из этого репозитория production-команду `bun run deploy:cloudflare`, production-конфигурацию `wrangler.jsonc` или `nitro deploy`. Не выполняйте production-миграции и не подключайте production D1, KV, Queues или secrets.
