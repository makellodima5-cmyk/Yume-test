# YUME — актуальное состояние проекта

Дата: 29 октября 2026 г.  
Репозиторий: makellodima5-cmyk/-YUME-Website, ветка main.

## Подтверждённые функции
- Веб-каталог и страницы тайтлов на метаданных Shikimori.
- Каталог Cloudflare D1 расширяем через административные инструменты; искусственный общий лимит записей не является требованием продукта.
- Поиск, фильтры, сортировка, пагинация, интерфейс RU/EN.
- «Избранное» и «Мой список» в localStorage конкретного браузера.
- Встроенные YouTube-трейлеры, если подходящий ID доступен.
- YUME не применяет собственную географическую фильтрацию тайтлов; ограничения внешнего видеопоставщика остаются под его контролем.

## Ограничения и границы текущей версии
- Доступность эпизодов зависит от Kodik API и его внешних ограничений.
- Не заявлять полный собственный видеохостинг.
- Не заявлять полную синхронизацию прогресса между устройствами без отдельного подтверждения.
- Реклама отключена и удалена из пользовательского интерфейса.
- Подключённая Яндекс Метрика.
- Исчерпывающий список всего контента, запрещённого в России.

## CI и релиз
Сборка и автоматические проверки Cloudflare Worker должны считаться пройденными только после успешного выполнения актуального GitHub Actions workflow. Исторические результаты не подтверждают состояние текущего коммита. Реальный production deploy необходимо подтверждать отдельно от CI.

## Правовые страницы
На дату аудита ссылки на политику, правила и страницу правообладателей ведут на заглушки/разделы профиля с текстом «скоро». До публичного запуска нужно внедрить полноценные утверждённые документы и проверить ссылки.
