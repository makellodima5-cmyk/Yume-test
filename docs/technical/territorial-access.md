# Территориальные ограничения доступа

**Текущий статус:** YUME не применяет собственные ограничения по стране посетителя к карточкам каталога и страницам тайтлов.

## Границы ответственности

- YUME отдаёт каталог и страницы тайтлов без географической фильтрации по стране IP.
- YUME не удаляет, не переписывает и не пытается обходить ограничения, которые устанавливает Kodik, видеоплеер или иной внешний поставщик контента.
- Если внешний поставщик не предоставляет видео из определённого региона, эта политика поставщика остаётся в силе.
- Геолокация IP больше не используется YUME для скрытия отдельных тайтлов.

## Совместимость

Файлы `src/data/territorial-restrictions.ts` и `src/data/territorial-restrictions.server.ts` временно сохраняют прежние функции как совместимые no-op, чтобы не менять без необходимости существующие server-function интерфейсы. Список YUME-ограничиваемых ID пуст.

## Проверки

Регрессионные тесты подтверждают, что YUME-фильтр возвращает весь переданный список для RU, иных стран и неизвестного кода. Отдельно необходимо проверять поведение внешнего видеопровайдера в его собственной среде: YUME не управляет такими ограничениями.
